🏠 House Prices Prediction — Machine Learning

📌 Project Overview

This project focuses on predicting house sale prices using Machine Learning regression models.
The main objective is to build models that can learn from different characteristics of residential properties and predict their expected SalePrice.
The project follows a complete Machine Learning workflow, starting from data understanding and exploratory analysis to data preprocessing, model training, evaluation, and final prediction.

🎯 Objectives

Understand and explore the dataset.

Analyze the distribution of house sale prices.

Identify and handle missing values.

Process numerical and categorical features.

Apply One-Hot Encoding to categorical variables.

Build and compare multiple regression models.

Evaluate model performance using RMSE and R².

Generate predictions for the test dataset.

🔄 Project Workflow

Data Understanding → EDA → Data Preprocessing → Feature Encoding → Model Training → Model Evaluation → Prediction → Submission

📊 Exploratory Data Analysis

The exploratory analysis was used to understand:

The distribution of SalePrice.

Important characteristics of the houses.

Relationships between numerical features and house prices.

Missing values and data quality.

🧹 Data Preprocessing

The preprocessing stage included:

Handling missing numerical values using median imputation.

Handling missing categorical values using the most frequent category.

Scaling numerical features.

Applying One-Hot Encoding to categorical features.

Using Scikit-learn Pipelines and ColumnTransformer to organize the preprocessing workflow.

🤖 Machine Learning Models

Four regression models were trained and compared:

Linear Regression

Ridge Regression

Random Forest Regressor

Gradient Boosting Regressor

📈 Model Evaluation

The models were evaluated using:

RMSE (Root Mean Squared Error)

R² Score

The model comparison was performed using validation data to understand the predictive performance of each approach.
